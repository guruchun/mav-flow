## 1. 개요

SCU(Stack Control Unit)에서 MG3로 전송되는 연료전지 텔레메트리 데이터를 시리얼 포트로 수신하여 실시간 모니터링하는 데스크톱 애플리케이션을 Python/Tkinter 기반에서 Flutter/Dart Windows 데스크톱 앱으로 전환하였다.

기존 `mg3-fat` 프로젝트(`D:\GitlabDmiTool\utils-dart\mg3-fat`)가 동일 환경에서 빌드·운용 중임을 확인하고, 해당 프로젝트의 디렉터리 구조, CMake 설정, Windows runner C++ 파일, 빌드 설정을 참조하여 신규 프로젝트를 구성하였다.

| `message_spec.yaml` | 패킷 프로토콜 전체 규격 (header/tail/CRC 파라미터, 191개 필드 정의) |

### 2.2 패킷 프로토콜

```
[ Header(1B: 0xFE) ] [ Payload(480B) ] [ CRC8(1B) ] [ Tail(1B: 0xFF) ]
= 483 bytes 총 프레임
```

- 페이로드 구성: `Base(100B, offset=0)` + `FuelCell(150B, offset=100)` + `Cells(230B, offset=250)`
- CRC8: polynomial=0x07, initial=0x00 (CRC-8/SMBUS), 범위=payload(raw[1:-2])
- 필드 인코딩: `converted = (raw_value - dmi_offset) × scale_factor` (Big-Endian)
- 배열 필드: `int16_array` — StackCellVoltage[0..88] (89개), StackTemperature[0..8] (9개)

### 2.3 런타임 의존성

- `pyserial >= 3.5`
- `PyYAML >= 6.0`
- `tkinter` (Python 표준 라이브러리)

## 5. 주요 구현 상세

### 5.1 시리얼 서비스 (serial_service.dart)

Python `SerialWorker`의 `threading.Thread` 수신 루프를 Dart `Isolate`로 대체하였다. 메인 Isolate와 worker Isolate는 `SendPort`/`ReceivePort`로 통신하며, `SerialEvent` sealed class로 이벤트를 타입 안전하게 전달한다.

```
SerialEvent
  ├── SerialConnected
  ├── SerialDisconnected
  ├── SerialError(message)
  └── SerialPacket(Uint8List data)
```

프레임 동기화 상태 머신은 Python과 동일한 로직을 유지한다:
- `IDLE` → `0xFE` 감지 시 `ACCUMULATING` 전환
- `ACCUMULATING` → 483바이트 누적 완료 시 패킷 전달, `IDLE` 복귀

### 5.2 패킷 파서 (packet_parser.dart)

`dart:typed_data`의 `ByteData`로 Big-Endian 바이너리를 디코딩한다.

```dart
// Python: struct.unpack(">h", raw_bytes)[0]
// Dart:
final bd = ByteData.sublistView(rawBytes);
rawValue = bd.getInt16(0, Endian.big);
```

CRC8 룩업 테이블 생성 및 계산 로직은 Python 구현을 그대로 포팅하였다.

### 5.3 상태 관리 (monitor_state.dart)

Python `MainWindow`의 인스턴스 변수와 메서드를 `ChangeNotifier` 기반 Provider 패턴으로 전환하였다.

| Python | Dart |
|---|---|
| `self._all_fields: list[dict]` | `allFields: List<FieldRow>` |
| `self._field_rows: dict` | 제거 (인덱스 기반 ListView로 대체) |
| `self._filter_type`, `self._search_text` | `filterType`, `searchText` |
| `self._rate_timestamps: list[float]` | `_rateTimestamps: List<DateTime>` |
| `root.after(50ms, poll_queues)` | `Stream<SerialEvent>.listen()` |
| `root.after(1000ms, update_status)` | `notifyListeners()` 즉시 갱신 |

### 5.4 UI 레이아웃 (main_screen.dart)

Python Tkinter의 `pack(fill="x")` / `pack(fill="both", expand=True)` 레이아웃을 Flutter `Column` + `Expanded`로 대응한다.

```
Column
├── SerialConfigPanel  (Wrap 레이아웃 — 포트 설정 드롭다운 + 버튼)
├── FilterPanel        (Row — ChoiceChip 필터 + TextField 검색)
├── Expanded
│   └── DataTablePanel (고정 헤더 Row + ListView.builder)
└── StatusBar          (Row — 패킷/에러/수신율 통계)
```
