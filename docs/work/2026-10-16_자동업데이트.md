# MAV-Flow 자동 업데이트 기능

**작성일**: 2026-10-16  
**프로젝트**: MAV-Flow (Flutter Windows Desktop)  
**기반**: `2026-10-09_추가기능-1차.md` 이후 작업

---

## 1. 개요

포터블 ZIP 배포 방식과 GitHub Releases를 활용한 자동 업데이트 기능을 구현했습니다.

### 선택한 방식

| 항목 | 내용 |
|------|------|
| **배포 형태** | 포터블 ZIP (설치 프로그램 없음) |
| **배포 채널** | GitHub Releases |
| **업데이트 확인** | GitHub API |
| **업데이트 방식** | 브라우저에서 다운로드 페이지 열기 |

---

```

└─────────────┘
```

## 3. 구현된 파일

### 3.1 모델 (`lib/models/update_info.dart`)

```dart
class UpdateInfo {
  final String latestVersion;    // 최신 버전
  final String currentVersion;   // 현재 버전
  final String downloadUrl;      // GitHub Release 페이지 URL
  final String releaseNotes;     // 릴리즈 노트
  final DateTime publishedAt;    // 발행일

  bool get hasUpdate;            // 업데이트 필요 여부 (semver 비교)
}
```

**버전 비교 로직:**
- Semantic Versioning (major.minor.patch) 지원
- `v` 접두사 자동 제거 (v1.0.0 → 1.0.0)

### 3.2 서비스 (`lib/services/update_service.dart`)

```dart
class UpdateService {
  static const String owner = 'guruchun';
  static const String repo = 'mav-flow';

  // 최신 릴리즈 확인
  static Future<UpdateInfo?> checkForUpdates(String currentVersion);

  // 다운로드 페이지 열기
  static Future<bool> openDownloadPage(String url);
}
```

**에러 처리:**
- 네트워크 오류 → null 반환
- API Rate Limit (403) → null 반환
- 릴리즈 없음 (404) → null 반환
- 10초 타임아웃

### 3.3 Settings UI (`lib/screens/main_screen.dart`)

`_UpdateCheckCard` 위젯 추가:

| 상태 | 표시 내용 |
|------|-----------|
| 기본 | "Current version: 1.0.0" + [Check] 버튼 |
| 확인 중 | "Checking..." + 로딩 스피너 |
| 최신 | "Up to date" (회색) |
| 업데이트 있음 | "Update available: v1.0.1" (녹색) + [Download] 버튼 |
| 오류 | "Unable to check for updates" (빨간색) |

### 3.4 앱 버전 관리 (`lib/main.dart`)

```dart
const String appVersion = '1.0.0';
```

- 앱 타이틀에 버전 표시: "MAV-Flow v1.0.0"
- Settings에서 버전 확인 시 사용

## 4. 빌드 및 배포

### 4.1 로컬 빌드 스크립트 (`scripts/build-release.ps1`)

```powershell
# 사용법
.\scripts\build-release.ps1

# 또는 버전 지정
.\scripts\build-release.ps1 -Version "1.0.1"
```

**실행 단계:**
1. `flutter pub get` - 의존성 설치
2. `flutter analyze` - 코드 분석
3. `flutter build windows --release` - 릴리즈 빌드
4. ZIP 아카이브 생성

**출력:**
```
build/release/mav-flow-1.0.0-windows-x64.zip
```

### 4.2 GitHub Actions (`.github/workflows/release.yml`)

**트리거:** `v*` 태그 푸시 시 자동 실행

```bash
git tag v1.0.1
git push origin v1.0.1
```

**워크플로우:**
1. Windows Runner에서 Flutter 설정
2. 의존성 설치 및 코드 분석
3. Windows 릴리즈 빌드
4. ZIP 아카이브 생성
5. GitHub Release 자동 생성 (ZIP 첨부)

**릴리즈 설정:**
- `generate_release_notes: true` - 자동 릴리즈 노트 생성
- `prerelease` - 태그에 `-`가 포함되면 프리릴리즈로 표시 (예: v1.0.1-beta)

## 6. 버전 업데이트 절차

새 버전 배포 시:

1. **코드 수정**
   ```yaml
   # pubspec.yaml
   version: 1.0.1+2
   ```
   ```dart
   // lib/main.dart
   const String appVersion = '1.0.1';
   ```

2. **커밋 및 태그**
   ```bash
   git add .
   git commit -m "chore: bump version to 1.0.1"
   git tag v1.0.1
   git push origin main --tags
   ```

3. **자동 배포**
   - GitHub Actions가 빌드 및 Release 생성
   - 사용자는 Settings에서 업데이트 확인 가능

## 9. 추가 구현 (2026-10-16)

### 9.1 시작 시 자동 업데이트 확인

**main.dart**
- 앱 초기화 후 2초 지연 후 백그라운드에서 업데이트 확인
- 네트워크 오류 시 무시 (사용자 경험에 영향 없음)

```dart
void _checkForUpdatesInBackground(AppSettings settings) {
  Future.delayed(const Duration(seconds: 2), () {
    if (mounted) {
      settings.checkForUpdates(appVersion);
    }
  });
}
```

### 9.2 업데이트 알림 배너

**main_screen.dart - _UpdateBanner**
- 메인 화면 상단에 MaterialBanner 표시
- 업데이트 가능 시에만 표시
- "나중에" 버튼으로 닫기 가능
- "업데이트" 버튼으로 다이얼로그 열기

### 9.3 인앱 다운로드 및 설치

**update_service.dart**

| 메서드 | 기능 |
|--------|------|
| `downloadUpdate()` | ZIP 파일 스트림 다운로드, 진행률 콜백 |
| `installUpdate()` | 배치 스크립트 생성 후 앱 재시작 |

**설치 프로세스:**
1. ZIP 파일을 임시 폴더에 다운로드
2. 배치 스크립트 생성 (mav-flow-update.bat)
3. 앱 종료
4. 스크립트가 ZIP 압축 해제 및 파일 교체
5. 앱 재시작

### 9.4 AppSettings 업데이트 상태 관리

**app_settings.dart**

```dart
UpdateInfo? _updateInfo;        // 업데이트 정보
bool _isCheckingUpdate;          // 확인 중 여부
bool _updateDismissed;           // 알림 닫힘 여부

bool get hasAvailableUpdate;     // 알림 표시 조건
```

### 9.5 업데이트 다이얼로그

**_UpdateDialog**
- 버전 정보 표시 (현재/새 버전)
- 릴리즈 노트 표시
- 다운로드 진행률 표시
- ZIP URL 없으면 브라우저로 이동
