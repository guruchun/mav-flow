## 3. 요구사항 정의

- **requirements.md**: 7개 기능 요구사항(FR) + 3개 비기능 요구사항(NFR)
- **design.md**: 4레이어 아키텍처, 8개 핵심 컴포넌트, 7개 Correctness Properties
- **tasks.md**: 17개 주요 태스크 (42개 세부 작업)

### 주요 요구사항

1. **메시지 수신/파싱**: MAVLink v2 프레임 동기화(0xFD), Data Table 업데이트
2. **메시지 생성/전송**: 수동 전송 + 자동전송(기본 500ms)
3. **역할 관리**: gen3, mc, fcc, gcs 4가지 역할
4. **메시지 규격 관리**: XML → JSON 변환, 런타임에서 JSON 참조
5. **화면 구성**: 좌/우 분할 (수신/송신), 역할 선택, 자동전송 제어

### 역할 정의

| 역할 | 설명 |
|------|------|
| gen3 | Communication Gateway 3세대 (데이터 수집, 프로토콜 변환, 메시지 전달) |
| mc | Mission Computer |
| fcc | Flight Control Computer |
| gcs | Ground Control Station (지상관제) |

### Data Table 설계

- TAG 형식: `{MessageName}.{FieldName}` (예: `HEARTBEAT.type`)
- 현재값(currentValue)과 전송값(sendValue) 분리 관리
- 수신/송신 화면에서 Data Table 공유

## 10. 사용 시나리오

이 프로그램은 여러 개의 인스턴스를 동시에 실행하여 각 인스턴스가 하나의 장치(역할)를 담당하도록 구성할 수 있습니다.

**예시:**
- 인스턴스 1: gen3 역할 (실제 H/W 장치)
- 인스턴스 2: fcc 역할 (시뮬레이션)
- 인스턴스 3: gcs 역할 (시뮬레이션)

실제 H/W 장치 하나와 나머지 주변 장치를 이 프로그램으로 시뮬레이션하여 실제 장치의 동작을 검증하는 용도로 사용됩니다.
