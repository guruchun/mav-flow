## 1. 개요

## 2. Dark Theme 완성

**lib/theme/app_theme.dart**
- `AppTheme.dark` 확장: cardTheme, listTileTheme, elevatedButtonTheme 추가

### 2.3 적용된 컴포넌트

## 3. Dropdown 가시성 및 스타일 개선

### 3.1 문제점

- Dark Theme에서 Dropdown 목록이 배경과 구분되지 않음
- Focus 상태에서 Border가 보이지 않음
- Port/Baud Dropdown 높이 불일치

### 3.2 해결 방법

**일관된 Dropdown 스타일**
- 모든 Dropdown 높이: 40px
- Border: `#30363D` (1px)
- Focus Border: `#58A6FF` (1px)
- Fill Color: `#161B22`
- Menu Color: `#2D333B`

**수정된 위젯**
- `role_selector.dart`: StatefulWidget으로 변환, Focus 상태 관리
- `message_selector.dart`: Focus 상태 추가
- `main_screen.dart`: Port/Baud Dropdown을 Custom Container+DropdownButton으로 변경

## 4. RX/TX 패널 일관성

### 4.1 구조 통일

TX 패널을 RX 패널과 동일한 구조로 변경:

| 요소 | RX Panel | TX Panel |
|------|----------|----------|
| Header 높이 | 48px | 48px |
| Message 라벨 | ✓ | ✓ (추가) |
| Search Box | ✓ | ✓ (추가) |
| All 옵션 | ✓ | ✓ (추가) |
| 컬럼명 | Field | Field (TAG→Field 변경) |
| Row 높이 | 40px | 40px |

### 4.2 Field 컬럼 표시 규칙

- **All 선택 시**: `MESSAGE.field` 형식 (예: `HEARTBEAT.type`)
- **특정 메시지 선택 시**: `field` 이름만 표시 (예: `type`)

### 4.3 Unit 컬럼 가운데 정렬

- RX Panel: Unit 값 Center 정렬
- TX Panel: Unit 값 또는 Bitmask 아이콘 Center 정렬

## 5. Enum 값 표시

### 5.1 RX Panel Enum 표시

수신된 필드가 Enum 타입인 경우 숫자 대신 Enum 이름 표시:

**예시**
- 숫자: `6`
- Enum: `QUADROTOR` (MAV_TYPE_QUADROTOR에서 접두어 제거)

**구현**
- `receive_panel.dart`에 `_shortenEnumName()` 헬퍼 함수 추가
- Enum 정의에서 값에 해당하는 Entry 검색
- 접두어(enum name + "_" 또는 "MAV_") 제거하여 간결하게 표시

### 5.2 TX Panel Enum Dropdown

- 기존 구현 유지 (FieldEditor에서 Enum Dropdown 제공)
- Bitmask가 아닌 Enum만 Dropdown으로 표시

## 6. Bitmask Editor

### 6.1 기능

Bitmask 타입 필드에 대해 체크박스 기반 편집 UI 제공:

**진입점**
- TX Panel의 Unit 컬럼에 편집 아이콘 (🖊️) 표시
- 아이콘 클릭 시 Dialog 팝업

**Dialog 구성**
- Title: 필드 이름
- Value 표시: 10진수 + 16진수 (예: `5 (0x5)`)
- Table: Checkbox | Bit | Description

### 6.2 구현 상세

**BitmaskEditorDialog 클래스** (`send_panel.dart`)
- StatefulWidget으로 `_currentValue` 상태 관리
- Checkbox 변경 시 비트 OR/AND 연산
- OK 버튼: 결과값 반환 → `state.updateSendValue()` 호출

**Bit 위치 계산**
- `_getBitPosition()`: value가 2의 거듭제곱인 경우 bit 위치 반환
- 정렬: entries를 value 오름차순으로 정렬 (b0이 첫 행)

**FieldEditor 값 동기화 문제 해결**
- `_lastSendValue` 변수 추가하여 실제 값 변경 추적
- `didUpdateWidget`에서 값 비교 로직 개선

## 7. Settings: XML → JSON 변환

### 7.1 기능

MAVLink XML 파일들을 JSON으로 변환하여 `messages.json` 생성:

**워크플로우**
1. Settings 화면에서 "Convert" 버튼 클릭
2. XML 파일이 있는 **폴더** 선택 (file_selector 사용)
3. 폴더 내 모든 `.xml` 파일 재귀 탐색
4. `role_config.json`에 정의된 메시지만 필터링
5. `assets/mavlink/messages.json`에 저장
6. 자동으로 새 규격 로드

### 7.2 구현

**main_screen.dart - `_convertSpec()`**
```dart
// 폴더 선택
final directory = await getDirectoryPath(...);

// XML 파일 탐색
final xmlFiles = await dir.list(recursive: true)
    .where((entity) => entity.path.endsWith('.xml'))
    .toList();

// 변환 실행
await state.convertMessageSpec(
  xmlPaths: xmlPaths,
  outputJsonPath: outputJsonPath,
  roleConfigPath: roleConfigPath,
);
```

**변경 사항**
- 단일 파일 선택 → 폴더 선택으로 변경
- 재귀적으로 모든 XML 파일 수집
- 진행 상황 Dialog 표시
- 성공/실패 SnackBar 표시
